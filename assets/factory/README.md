# Factory wavetables (third-party data)

These WAV files are the 285 tables selected in `../wavetable-curation.json` and
packed into the firmware's wave bank by `tools/build_wavebank.py`.

| Folder | Source | Rights holder |
| --- | --- | --- |
| `wavetables/ms2000/` | Korg MS2000 / DWGS single-cycle waveforms | Korg Inc. |
| `wavetables/virus/` | Access Virus wavetables | Access Music Electronics GmbH |
| `wavetables/growl/` | "Spectral Growl" wavetables — source to be confirmed | to be confirmed |

to them is granted. See [`LICENSING.md`](../../LICENSING.md#third-party-data-no-licence-granted).
